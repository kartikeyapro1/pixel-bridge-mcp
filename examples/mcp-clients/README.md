# MCP client configuration examples

- `mcp-servers.json`: the common `mcpServers` format used by most desktop and IDE clients.
- `vscode-mcp.json`: VS Code's `.vscode/mcp.json` format.

Replace the paths with absolute paths on your machine. Keys are not configured here: store them
with `pixelbridge key set gemini` (see ../../docs/credentials.md).
