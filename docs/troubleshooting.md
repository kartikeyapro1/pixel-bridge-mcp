# Troubleshooting

Start with `pixelbridge status` (or the `get_status` tool). Its `setup` list names anything missing.
Every error has a `code` and usually a `hint`.

| Symptom / code                                          | Cause and fix                                                                                                                                                                                                                       |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tools don't appear in the client                        | Run `node /path/to/dist/mcp-entry.js` in a terminal: startup errors go to stderr. Check the path in the client config is absolute, then restart the client.                                                                         |
| `PROVIDER_NOT_CONFIGURED`                               | No key found. Run `pixelbridge key status`, then `pixelbridge key set gemini`. If you use environment variables, they must be in the **server's** environment (the `env` block of the client config).                               |
| Stored key not used                                     | An environment variable takes precedence over the stored key. `key status` shows `environment`; remove the variable or update it.                                                                                                   |
| `PROVIDER_AUTH` (401/403)                               | Invalid key, or billing not enabled on the Google Cloud project. `pixelbridge key test gemini` checks the key for free.                                                                                                             |
| `PROVIDER_RATE_LIMITED` (429)                           | Quota or rate limit. Wait, or check your quota in Google AI Studio.                                                                                                                                                                 |
| `PROVIDER_REJECTED` (400)                               | The provider refused the parameters or the prompt (including safety filters). The message contains the provider's reason. Not billed.                                                                                               |
| `PROVIDER_UNSUPPORTED`                                  | The selected provider can't do that, e.g. transparent backgrounds or masks with Gemini (use `provider: "openai"` if you have an OpenAI key).                                                                                        |
| `PRICE_UNKNOWN`                                         | The model has no known price, so PixelBridge refuses rather than guess. Use a listed model ([providers.md](providers.md)).                                                                                                          |
| `APPROVAL_REQUIRED`                                     | Expected for calls above the threshold. Approve the shown estimate (`confirmCostUsd` / `--yes`) or lower quality, size or duration.                                                                                                 |
| `BUDGET_EXCEEDED`                                       | The project or provider budget would be exceeded. `get_budget` shows the ledger. "unknown" entries are timed-out requests that may have been billed; check your Google billing, then raise `budget.projectLimitUsd` if appropriate. |
| `CONCURRENCY_LIMIT`                                     | Too many paid requests or video jobs running. Wait for them, or raise `budget.maxInFlight`.                                                                                                                                         |
| `PROVIDER_TIMEOUT` on a generation                      | The request may still have been processed and billed. It is not retried automatically. Check billing before retrying.                                                                                                               |
| Video tool blocks for minutes                           | The API rejected background mode and PixelBridge fell back to a synchronous call. The video is still produced.                                                                                                                      |
| `DOWNLOAD_FAILED`                                       | Call `get_job` again; downloads are retried. Results are kept by Google for a limited time.                                                                                                                                         |
| `BLENDER_NOT_FOUND`                                     | Install Blender 4.2+ or set `blender.path` / `BLENDER_PATH` to the executable (`blender.exe` on Windows).                                                                                                                           |
| `BLENDER_TIMEOUT`                                       | Lower render resolution, subdivision levels or segment counts, or raise `blender.timeoutMs`.                                                                                                                                        |
| `REFINEMENT_LIMIT`                                      | The collection reached `pipeline.maxModelVersions`. Review the renders, then raise the limit if more iterations are wanted.                                                                                                         |
| `PATH_OUTSIDE_PROJECT`                                  | Files are only read from and written to the project directory. Copy the file into the project.                                                                                                                                      |
| Files appear in the wrong folder                        | The client started the server in another directory. Set `PIXELBRIDGE_PROJECT_ROOT` in the server's `env`.                                                                                                                           |
| `Could not decrypt the stored GEMINI_API_KEY` (Windows) | The key was stored by another Windows account. Run `pixelbridge key set gemini` again.                                                                                                                                              |
